Un juego sobre límites, lectura del entorno y decisiones bajo presión.

Aconcagua: Stone Sentinel propone una experiencia contemplativa y exigente: no se trata de “conquistar” la montaña, sino de interpretar señales, gestionar riesgo y decidir hasta dónde avanzar.

Por qué este proyecto importa

Combina enfoque documental, diseño sistémico y narrativa de decisión para construir una experiencia de montaña que prioriza observación, criterio y consecuencias, en lugar de power-fantasy o acción impulsiva.

La montaña manda

Altitud, clima y terreno son sistemas activos que condicionan cada acción.

Información parcial

El jugador decide con señales limitadas y confianza variable: no hay certeza absoluta.

Fracasar también enseña

Detenerse, retirarse o reconfigurar estrategia son desenlaces válidos y significativos.

Sistema de juego y propuesta técnica

El prototipo web v1 utiliza un engine de resolución por turnos (EP/BT) con datos externos para personajes, acciones, escenarios y outcomes, manteniendo consistencia entre diseño, runtime y documentación pública.

Pipeline central

  • Acción del jugador + recursos/tiempo.
  • Presión ambiental y tolerancia corporal.
  • Percepción (señal + confianza + tendencia).
  • Resolución de outcome y actualización de estado.

Outcomes canónicos

El sistema no fuerza “éxito único”: evalúa desempeño, seguridad, tiempo y recursos para clasificar resultados con consecuencias claras y trazables.

Summit and Safe Return

Cumbre + salida segura del parque.

High Point Return

Máxima cota alcanzada sin cumbre final.

Strategic Retreat / Rescue

Retirada estratégica o rescate según estado.

Collapse / Permit / Window

Colapsos, vencimientos o ventana cerrada por riesgo acumulado.
